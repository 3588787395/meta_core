# 三软件本地板块数据解析完整技术文档

> 基于 LocalFileProvider 实现 — 通达信 / 大智慧 / 同花顺
> 本地文件解析 + 板块指数映射 + 双向求解

---

## 一、概述

### 1.1 设计目标

LocalFileProvider 是一个**本地文件数据源提供者**，负责解析通达信（TDX）、大智慧（DZH）、同花顺（THS）三大股票软件的本地配置文件，提取以下三类独立数据：

| 数据类型 | 说明 | 典型用途 |
|---------|------|---------|
| **系统板块** | 概念、行业、风格、指数、地区等官方分类 | 板块分类筛选 |
| **板块指数** | 衡量板块走势的指数代码（如 880xxx） | 由指数代码反查成分股 |
| **自定义板块** | 用户自建的板块分组 | 用户自定义股票池 |
| **自选股** | 用户收藏的个股列表 | 自选股监控 |

### 1.2 核心设计原则

1. **三软件数据完全独立**：各软件数据独立解析、独立存储、独立更新，通过 `source` 字段区分（`tdx_local` / `dzh_local` / `ths_local`）
2. **板块与板块指数分离**：板块是股票集合，板块指数代码是衡量走势的指数，二者一一对应但概念不同
3. **文件级缓存**：按文件路径缓存解析结果，文件修改时间变化时自动刷新
4. **优雅降级**：文件不存在时返回空列表，不抛出异常

### 1.3 类结构

```
LocalFileProvider (继承 DataSourceProvider)
├── 配置加载：_load_paths_config()
├── 路径探测：_detect_homes() / _detect_from_registry()
├── 文件缓存：_read_file_cached() / _cache
├── 通用工具：_to_tq_code() / _code_prefix_map / _tdx_market_digit
├── TDX 解析器：_get_user_sector_tdx() / _parse_tdx_blocknew_cfg() / ...
├── DZH 解析器：_get_user_sector_dzh() / ...
├── THS 解析器：_get_user_sector_ths() / _find_ths_self_stock_json() / ...
├── 股票名称映射：get_stock_name_map()
├── 对外 API 方法
│   ├── get_system_sectors() — 系统板块（按数据源分组）
│   ├── get_sector_index_list() — 板块指数列表
│   ├── get_custom_blocks_grouped() — 自定义板块（含成分股）
│   ├── get_favorites_grouped() — 自选股（含成分股）
│   ├── get_members_by_sector_index_code() — 由板块指数代码查成分股
│   └── get_sectors_by_stock() — 由个股查所属板块
└── 向后兼容方法
    ├── get_system_sectors_flat()
    ├── get_user_sector()
    └── get_stock_list_by_type()
```

## 二、客户端安装路径探测

### 2.1 探测优先级

LocalFileProvider 启动时自动探测三大软件的安装目录，优先级从高到低：

| 优先级 | 方式 | 说明 |
|-------|------|------|
| 1 | 配置文件显式指定 | `local_file_paths.json` 中 `default_homes` 字段 |
| 2 | 环境变量 | 各软件对应的环境变量名 |
| 3 | Windows 注册表 | 从 HKLM/HKCU 读取安装路径 |
| 4 | 默认路径依次尝试 | 常见安装路径列表 |

### 2.2 配置文件位置

配置文件路径由 `CONFIG_PATH` 定义，通常为：
```
meta_core/config/local_file_paths.json
```

### 2.3 市场代码映射规则

从配置文件加载，缺失时使用内置默认值：

- `tdx_market_digit`：通达信自选股文件中首位数字 → 市场映射（如 `1` → SH）
- `code_prefix_to_market`：股票代码首位 → 市场映射（如 `6` → SH，`0`/`3` → SZ，`4`/`8` → BJ）

## 三、通达信（TDX）文件解析

### 3.1 目录结构

```
{TDX_HOME}/
├── T0002/
│   ├── blocknew/           # 自定义板块目录
│   │   ├── *.blk           # 每个板块一个 .blk 文件（二进制，含成分股）
│   │   └── blocknew.cfg    # 自定义板块索引（板块名称 ↔ 板块代码映射）
│   ├── hq_cache/
│   │   ├── infoharbor_ex.code    # 股票名称库
│   │   ├── infoharbor_block.dat  # 概念/风格/指数板块成分股
│   │   ├── tdxhy.dat            # 行业板块成分股
│   │   ├── tdxzs.cfg            # 板块指数代码映射（行业/地区）
│   │   └── base.dbf             # 地区信息（BaseInfo）
│   └── blocknew/zxg.blk    # 自选股文件
```

### 3.2 自选股解析（zxg.blk）

**文件格式**：文本文件，每行一只股票

**行格式**：市场标识 + 股票代码（6位）
- 首字符为市场标识：`1`=SH（沪市），`0`=SZ（深市）
- 后6位为股票代码

**示例**：
```
1600000    ; 600000.SH 浦发银行
0000001    ; 000001.SZ 平安银行
```

**解析方法**：`_parse_tdx_zxg()`

### 3.3 自定义板块解析

#### 3.3.1 板块索引（blocknew.cfg）

**文件格式**：二进制文件，每条记录 **120 字节**

**记录结构**：
| 偏移 | 长度 | 内容 | 编码 |
|------|------|------|------|
| 0 | 50 字节 | 板块名称 | GBK 编码，遇 0 截断 |
| 50 | 50 字节 | 板块代码 | ASCII 编码，遇 0 截断 |
| 100 | 20 字节 | 保留/其他信息 | - |

**解析方法**：`_parse_tdx_blocknew_cfg()`

**返回值**：`{板块代码: 板块名称}` 字典映射

#### 3.3.2 板块成分股（*.blk）

每个自定义板块对应一个 `.blk` 文件，文件名即为板块代码。

**文件格式**：二进制，每 32 字节（或固定长度）一条股票记录

**解析方法**：`_parse_tdx_blk()`

#### 3.3.3 解析流程

1. 扫描 `T0002/blocknew/` 目录下所有 `.blk` 文件
2. 读取 `blocknew.cfg` 获取板块名称映射
3. 优先使用 `blocknew.cfg` 中的名称，降级使用文件名
4. 逐个解析 `.blk` 文件获取成分股

### 3.4 系统板块解析

| 分类 | 数据源文件 | 说明 |
|------|-----------|------|
| 概念 | `infoharbor_block.dat` | 含板块指数代码（880xxx） |
| 风格 | `infoharbor_block.dat` | 含板块指数代码（880xxx） |
| 指数 | `infoharbor_block.dat` | 含板块指数代码（880xxx） |
| 行业 | `tdxhy.dat` + `tdxzs.cfg` | 行业代码（Txxxxxx）→ 指数代码映射 |
| 地区 | `base.dbf` + `tdxzs.cfg` | 地区序号 → 指数代码映射 |

### 3.5 板块指数代码映射

**文件**：`tdxzs.cfg`

**格式**：文本配置，每个板块指数一行，含 type 字段：
- `type=1`：概念/风格/指数（直接从 infoharbor_block.dat 头行获取）
- `type=2`：行业（desc 为 Txxxxxx 行业代码）
- `type=3`：地区（desc 为地区序列号）

**映射关系**：
```
板块指数代码 (880xxx) ←→ 板块名称 ←→ 成分股列表
```

## 四、大智慧（DZH）文件解析

### 4.1 目录结构

```
{DZH_HOME}/
├── cfg/
│   ├── block.ini          # 系统板块配置
│   ├── zxg.cfg            # 自选股配置
│   └── user/              # 用户配置
├── USERDATA/
│   ├── block/             # 系统板块缓存目录（*.BLK）
│   └── SelfSelect/        # 自选股相关
└── *.ABK                  # 自定义板块数据文件
```

### 4.2 自选股解析（zxg.cfg）

**文件格式**：INI 配置格式

**解析方法**：`_parse_dzh_zxg_cfg()`

### 4.3 自定义板块解析

#### 4.3.1 权威来源：ABK 文件 "自定义板块" section

大智慧的自定义板块存储在 **ABK 文件**中，其中有专门的 **"自定义板块" section**。

**这是自定义板块的唯一权威来源**，应优先使用。

**解析方法**：`_get_user_sector_dzh()` → 优先从 ABK 提取

#### 4.3.2 USERDATA/block 目录（降级方案）

`USERDATA/block/` 目录下的 `.BLK` 文件主要是**系统板块缓存**，包含大量官方分类板块。

**⚠️ 注意**：不能将该目录下所有 BLK 文件都当作自定义板块，否则会导致自定义板块数量异常庞大（几百个），与用户实际创建的自定义板块不符。

### 4.4 系统板块与板块指数

大智慧系统板块数据丰富，含概念、行业、风格、指数、地区等分类。

**板块指数数量**：约 1200+ 个

## 五、同花顺（THS）文件解析

### 5.1 目录结构

```
{THS_HOME}/
├── hexin/
│   ├── ZXG.cfg            # 自选股（旧版）
│   ├── Block.cfg          # 板块配置
│   └── BlockUpdate/       # 板块更新数据
│       └── block_22.ini   # 自定义板块配置
├── thsguest_*/            # 游客用户数据目录
│   └── SelfStockInfo.json # 自选股 JSON
├── 股神之师/               # 股神之师方案目录
│   ├── SelfStockInfo.json # 自选股 JSON
│   └── custom_block/      # 自定义板块
├── stockspirit.json       # 股票精灵（含股票名称映射）
└── stocknametable.txt     # 股票名称表
```

### 5.2 自选股解析

#### 5.2.1 优先级

自选股解析按以下优先级尝试：

| 优先级 | 来源 | 格式 | 说明 |
|-------|------|------|------|
| 1 | SelfStockInfo.json | JSON | 游客/登录用户目录下，首选 |
| 2 | BlockUpdate 自定义板块中的"自选股" | INI | 降级方案 |
| 3 | hexin/ZXG.cfg | 文本 | 旧版格式，最后降级 |

#### 5.2.2 SelfStockInfo.json 格式

**文件位置**（按文件大小选最大有效文件）：
- `{THS_HOME}/thsguest_*/SelfStockInfo.json`
- `{THS_HOME}/股神之师/SelfStockInfo.json`
- `{THS_HOME}/userdata_*/SelfStockInfo.json`

**JSON 结构**：
```json
[
  {"C": "603690", "M": "17", "P": "34.57", "T": "20260625"},
  {"C": "000100", "M": "33", "P": "5.12", "T": "20260617"}
]
```

**字段说明**：
| 字段 | 含义 | 取值 |
|------|------|------|
| C | 股票代码 | 6 位数字 |
| M | 市场代码 | 17=SH, 33=SZ, -105=BJ |
| P | 价格/成本价 | 数值字符串 |
| T | 日期 | YYYYMMDD 格式 |

**解析方法**：`_find_ths_self_stock_json()` + `_parse_ths_self_stock_json()`

**文件选择策略**：遍历所有候选路径，选择文件大小 > 10 字节且最大的文件（避免选中内容为 `null` 的空文件）。

### 5.3 自定义板块解析

| 优先级 | 来源 | 说明 |
|-------|------|------|
| 1 | BlockUpdate/custom (block_22.ini) | 新版自定义板块配置 |
| 2 | hexin/Block.cfg | 旧版板块配置 |
| 3 | 股神之师/custom_block/ | 方案级自定义板块 |

### 5.4 板块指数

同花顺板块指数约 **596 个**，从板块配置文件中提取。

## 六、股票名称映射

### 6.1 多源合并策略

股票名称从多个数据源合并获取，优先级从高到低：

| 来源 | 文件 | 适用软件 |
|------|------|---------|
| 1 | stockspirit.json | 同花顺（最完整） |
| 2 | infoharbor_ex.code | 通达信 |
| 3 | stocknametable.txt | 同花顺补充 |
| 4 | 各板块文件内嵌名称 | 各软件 |

### 6.2 get_stock_name_map()

**返回值**：`{市场+代码: 股票名称}` 字典

**Key 格式**：`SH600000` / `SZ000001` / `BJ430001`

**用途**：
- 填充自定义板块成分股名称
- 填充自选股名称
- 补全系统板块成分股名称

### 6.3 名称填充逻辑

在 `get_custom_blocks_grouped()` 和 `get_favorites_grouped()` 中：

1. 调用 `get_stock_name_map()` 获取名称映射
2. 遍历每只成分股
3. 如果成员本身已有 name 字段（如 THS SelfStockInfo.json），直接使用
4. 否则用 `市场+代码` 在名称映射中查找
5. 支持跨市场模糊匹配（如代码可能在 SH/SZ/BJ 间不确定时依次尝试）

## 七、板块 ↔ 板块指数 ↔ 个股 双向映射求解

### 7.1 核心概念辨析

| 概念 | 含义 | 示例 |
|------|------|------|
| **板块** | 一组股票的集合 | "黑龙江"板块、"机器人"概念 |
| **板块指数代码** | 衡量该板块整体走势的指数代码 | 880201（黑龙江）、880515（通达信88） |
| **成分股** | 板块包含的个股 | 600000.SH 浦发银行 |

**关系**：一个板块对应一个板块指数代码，一一对应。

### 7.2 由板块指数代码查成分股

**方法**：`get_members_by_sector_index_code(index_code, source=None)`

**求解路径**：

```
880xxx（板块指数代码）
  │
  ├─ 概念/风格/指数类：直接匹配 infoharbor_block.dat 头行第4字段
  │    └→ 板块名 → 成分股列表
  │
  ├─ 行业类：匹配 tdxzs.cfg 中 type=2 的 desc(Txxxxxx)
  │    └→ 行业代码 Txxxxxx → tdxhy.dat → 成分股列表
  │
  └─ 地区类：匹配 tdxzs.cfg 中 type=3 的 desc(序列号)
       └→ 地区序号 → base.dbf DY字段 → 成分股列表
```

**返回值**：
```python
{
    "index_code": "880201",
    "sector_name": "黑龙江",
    "sector_type": "region",
    "members": ["SH600000", "SZ000001", ...],
    "member_count": 10,
    "source": "tdx_local"
}
```

### 7.3 由个股查所属板块

**方法**：`get_sectors_by_stock(stock_code, source=None)`

**返回值**：
```python
{
    "tdx_local": {
        "concept": [{"code": "机器人", "name": "机器人", "sector_index_code": "880xxx"}, ...],
        "industry": [...],
        "style": [...],
        "region": [...],
        "index": [...]
    },
    "dzh_local": {...},
    "ths_local": {...}
}
```

## 八、对外 API 方法详解

### 8.1 get_system_sectors()

获取各软件的系统板块（按数据源 + 分类分组）。

**返回结构**：
```python
{
    "tdx": {
        "concept": [{"code": "", "name": "", "sector_index_code": "", ...}, ...],
        "industry": [...],
        "style": [...],
        "region": [...],
        "index": [...]
    },
    "dzh": {...},
    "ths": {...}
}
```

### 8.2 get_sector_index_list(source=None)

获取各软件的板块指数列表。

**参数**：
- `source`：`'tdx'` / `'dzh'` / `'ths'` / `None`（全部）

**返回结构**：
```python
{
    "tdx": [
        {
            "code": "880201",
            "name": "黑龙江",
            "sector_index_code": "880201",
            "source": "tdx_local",
            "type": "index",
            "sub_type": "region",
            "description": "TDX板块指数 黑龙江",
            "member_count": 10
        },
        ...
    ],
    "dzh": [...],
    "ths": [...]
}
```

### 8.3 get_custom_blocks_grouped(source=None)

获取各软件的自定义板块（含成分股和名称）。

**返回结构**：
```python
{
    "tdx": [
        {
            "code": "0722JD",
            "name": "0722节点",
            "source": "tdx_local",
            "members": [
                {"stock_code": "000672.SZ", "code": "000672.SZ", "name": "上峰材料"},
                {"stock_code": "000877.SZ", "code": "000877.SZ", "name": "天山股份"},
                ...
            ],
            "member_count": 55
        },
        ...
    ],
    "dzh": [...],
    "ths": [...]
}
```

### 8.4 get_favorites_grouped(source=None)

获取各软件的自选股（含成分股和名称）。

**返回结构**：
```python
{
    "tdx": [{
        "code": "tdx_favorites",
        "name": "TDX自选股",
        "source": "tdx_local",
        "members": [
            {"stock_code": "000636.SZ", "code": "000636.SZ", "name": "风华高科"},
            ...
        ],
        "member_count": 1129
    }],
    "dzh": [...],
    "ths": [...]

```

**说明**：每个数据源仅返回一条记录（该客户端的全部自选股）。

### 8.5 get_members_by_sector_index_code(index_code, source=None)

由板块指数代码输出成分股。详见第七章。

### 8.6 get_sectors_by_stock(stock_code, source=None)

由个股查询所属板块。详见第七章。

## 九、数据流向与 API 集成

### 9.1 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                      Web 前端 (panel.js)                    │
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────────┐  │
│  │ 板块选择大窗口│  │ 备选池属性面板│  │ 成分股展示       │  │
│  └──────┬───────┘  └──────┬───────┘  └────────┬─────────┘  │
└─────────┼─────────────────┼───────────────────┼────────────┘
          │                 │                   │
┌─────────▼─────────────────▼───────────────────▼────────────┐
│                    API 层 (pool_api.py)                    │
│  /sectors  /custom-blocks  /favorites-list  /sectors/{id}/… │
└─────────────────────────────┬──────────────────────────────┘
                              │
              ┌───────────────▼───────────────┐
              │   CandidatePoolResolver       │
              │   (备选池解析器)               │
              └───────────────┬───────────────┘
                              │
              ┌───────────────▼───────────────┐
              │   LocalFileProvider           │
              │   (本地文件解析器)             │
              └───────────────┬───────────────┘
                              │
              ┌───────────────▼───────────────┐
              │   本地文件系统                 │
              │   TDX / DZH / THS 配置文件     │
              └───────────────────────────────┘
```

### 9.2 关键 API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/sectors` | GET | 系统板块树 |
| `/sector-index-list` | GET | 板块指数列表 |
| `/custom-blocks` | GET | 自定义板块列表 |
| `/favorites-list` | GET | 自选股列表 |
| `/sectors/{sector_id}/members` | GET | 板块成分股查询 |
| `/sectors/by-index/{index_code}/members` | GET | 由板块指数代码查成分股 |
| `/stocks/{stock_code}/sectors` | GET | 由个股查所属板块 |

### 9.3 数据库同步（SectorSyncService）

LocalFileProvider 解析的板块数据可通过 SectorSyncService 同步到数据库：

- `sectors` 表：板块基本信息
- `sector_members` 表：板块成分股关系
- `stocks` 表：股票基本信息

同步后可通过数据库进行更复杂的查询。

## 十、备选池集成

### 10.1 备选池类型（CandidatePoolResolver）

| type 值 | 类型 | 数据来源 |
|---------|------|---------|
| 0 | 全市场 / 自动选股 | 全市场股票 |
| 1 | 按代码 | 用户输入代码列表 |
| 2 | 全部A股 | 系统板块-全部A股 |
| 3 | 自选股 | 各软件自选股合并 |

| 6 | 板块指数 | 由板块指数代码查成分股 |
| 7 | 市场分类 | 按交易所/市场分类 |

### 10.2 与 LocalFileProvider 的关系

LocalFileProvider 为备选池解析器提供底层数据支撑：
- 自选股（type=3）→ `get_favorites_grouped()`
- 自定义板块（type=4）→ `get_custom_blocks_grouped()`
- 系统板块（type=5）→ `get_system_sectors()`
- 板块指数（type=6）→ `get_members_by_sector_index_code()`

## 十二、历史问题与修复记录

### 12.1 通达信自定义板块名称未显示

**问题**：自定义板块名称直接用文件名，不是真实名称

**原因**：未解析 `blocknew.cfg` 二进制索引文件

**修复**：新增 `_parse_tdx_blocknew_cfg()` 方法，从 120 字节/条的记录中提取板块名称和代码映射

### 12.2 DZH 自定义板块数量过多

**问题**：大智慧自定义板块有几百个，远多于用户实际创建的

**原因**：错误地将 `USERDATA/block/` 下所有 `.BLK` 文件都当作自定义板块，实际这些是系统板块缓存

**修复**：优先使用 ABK 文件的 **"自定义板块" section** 作为权威来源，仅返回用户真正创建的自定义板块（约 5 个）

### 12.3 THS 自选股缺失

**问题**：同花顺自选股显示 0 只

**原因**：
1. 未支持 `SelfStockInfo.json` 格式（仅支持旧版 ZXG.cfg）
2. `thsguest_*` 目录下的文件内容为 `null`（空文件）
3. 有效文件在 `股神之师/` 目录下未被扫描到

**修复**：
1. 新增 `_find_ths_self_stock_json()` 和 `_parse_ths_self_stock_json()`
2. 新增 `股神之师` 目录为候选路径
3. 选择文件时按大小选最大的有效文件（>10字节）

### 12.4 成分股名称缺失

**问题**：自定义板块和自选股的成分股只显示代码，名称为空或"名称待补全"

**原因**：members 字段仅返回代码字符串，未填充名称

**修复**：
1. 在 `get_custom_blocks_grouped()` 和 `get_favorites_grouped()` 中调用 `get_stock_name_map()`
2. members 字段从字符串列表改为 `{stock_code, code, name}` 字典列表
3. 前端 panel.js 自动兼容两种格式（已有判断逻辑）
