# 公式引擎使用指南

## 1. 引擎概述

### HQChartPy2 是什么

HQChartPy2 是 meta_core 内置的 **C++ 技术指标计算引擎**，以 Python 模块形式封装（`HQChartPy2`），位于 `vendor/` 目录下。它提供高性能的批量公式计算能力，支持通达信（TDX）和大智慧（DZH）的公式语法。

### 核心能力

- **通达信/大智慧公式语法**：完整支持 TDX/DZH 指标公式、选股公式、专家系统公式语法
- **高性能批量计算**：C++ 底层引擎，可对多只股票批量执行公式计算
- **多周期支持**：支持分笔、1分钟、5分钟、15分钟、30分钟、60分钟、日线、周线、月线等周期
- **双引擎降级**：当 HQChartPy2 不可用时，可降级到通达信 TQ 量化 DLL（TPythClient.dll）进行公式计算

### 在 meta_core 中的集成方式

公式引擎通过以下模块集成到 meta_core 中：

```
meta_core/
├── services/providers/hqchart_provider.py   # HQChartPy2 引擎封装，实现 DataSourceProvider 接口
├── core/formula_engine.py                   # 纯 Python 公式引擎（兜底路径，支持简单 TDX 公式）
├── core/formula_router.py                   # 公式路由分发器，在 Python 引擎与 HQChart 间路由
├── core/evaluators.py                       # TDX 条件评估器，nset 0~5 六种评估器
├── api/system_api.py                        # 公式管理 REST API（create_formula_router()，/api/formula/*）
├── config/builtin_formulas.json             # 内置公式库
└── config/custom_formulas.json              # 用户自定义公式库
```

注：`runtime/tdx_evaluators.py` 和 `api/formula_api.py` 为兼容别名，实际实现已迁移至上述路径。

**数据流**：

```
用户请求 → api/system_api.py → FormulaRouter → HQChartProvider → IHQDataImpl → TQ 适配器
                                              ↓                              ↓
                                      PythonFormulaEngine              K 线数据源
                                      （兜底路径）                          ↓
                                                                  HQChartPy2 C++ 引擎
                                                                        ↓
                                                                    计算结果
```

**公式路由**（`core/formula_router.py`）：

FormulaRouter 是公式评估的统一入口，根据公式复杂度与数据周期在两个引擎间路由：
- 简单公式（仅含 MA/REF/CROSS/HHV/LLV/SUM/COUNT/STD 等函数）+ 1分钟/tick 周期 → PythonFormulaEngine（纯 Python 兜底）
- 其他情形 → HQChartPy2 C++ 引擎
- HQChart 不可用且不满足回退条件 → 抛出 RuntimeError（禁止静默回退）

**股票池中的集成**（`core/evaluators.py`）：

```
股票池边条件 → tdx_evaluators.eval_tdx_condition()
    ├── nset=0: eval_nset0_indicator()      → 技术指标公式
    ├── nset=1: eval_nset1_condition_formula() → 条件选股公式
    ├── nset=2: eval_nset2_expert_system()  → 专家系统公式
    ├── nset=3: eval_nset3_financial_scalar() → 最新财务标量
    ├── nset=4: eval_nset4_market_scalar()  → 实时行情标量
    └── nset=5: eval_nset5_set_operation()  → 集合运算（直通）
```

## 2. 支持的公式语法

### 基本语法

TDX/DZH 公式语法基于类 C 表达式，每条语句以分号（`;`）结尾：

| 语法元素 | 说明 | 示例 |
|---------|------|------|
| 变量赋值 `:=` | 定义中间变量，不输出到图表 | `MA5:=MA(CLOSE,5);` |
| 输出变量 `:` | 定义输出变量，输出到图表 | `MA1:MA(CLOSE,5);` |
| 函数调用 | 调用内置函数 | `MA(CLOSE,20)` |
| 参数定义 | 公式顶部定义可调参数 | `N:5,10,20;` |
| 注释 | 使用 `{ }` 或 `//` 注释 | `{这是一行注释}` |

### 常用函数

#### 数据引用函数

| 函数 | 说明 | 用法示例 |
|------|------|---------|
| `CLOSE` / `C` | 收盘价 | `CLOSE` |
| `OPEN` / `O` | 开盘价 | `OPEN` |
| `HIGH` / `H` | 最高价 | `HIGH` |
| `LOW` / `L` | 最低价 | `LOW` |
| `VOL` / `V` | 成交量 | `VOL` |
| `AMOUNT` / `AMO` | 成交额 | `AMOUNT` |

#### 统计函数

| 函数 | 说明 | 用法示例 |
|------|------|---------|
| `MA(X, N)` | N 周期简单移动平均 | `MA(CLOSE, 5)` |
| `EMA(X, N)` | N 周期指数移动平均 | `EMA(CLOSE, 12)` |
| `SMA(X, N, M)` | N 周期加权移动平均，权重 M | `SMA(CLOSE, 3, 1)` |
| `HHV(X, N)` | N 周期内 X 的最高值 | `HHV(HIGH, 20)` |
| `LLV(X, N)` | N 周期内 X 的最低值 | `LLV(LOW, 20)` |
| `STD(X, N)` | N 周期内 X 的标准差 | `STD(CLOSE, 20)` |
| `REF(X, N)` | N 周期前的 X 值 | `REF(CLOSE, 1)` |
| `SUM(X, N)` | N 周期内 X 的求和 | `SUM(VOL, 5)` |
| `COUNT(X, N)` | N 周期内条件 X 成立次数 | `COUNT(CLOSE>OPEN, 5)` |
| `AVEDEV(X, N)` | N 周期内 X 的平均绝对偏差 | `AVEDEV(CLOSE, 14)` |

#### 逻辑与条件函数

| 函数 | 说明 | 用法示例 |
|------|------|---------|
| `CROSS(A, B)` | A 上穿 B（金叉） | `CROSS(MA(C,5), MA(C,10))` |
| `IF(C, A, B)` | 条件判断，C 成立返回 A，否则返回 B | `IF(CLOSE>OPEN, 1, 0)` |
| `MAX(A, B)` | 取 A 和 B 的最大值 | `MAX(CLOSE, OPEN)` |
| `MIN(A, B)` | 取 A 和 B 的最小值 | `MIN(CLOSE, OPEN)` |
| `ABS(X)` | 取 X 的绝对值 | `ABS(CLOSE - REF(CLOSE, 1))` |

### 支持的运算符

| 类型 | 运算符 | 说明 |
|------|-------|------|
| 算术 | `+` `-` `*` `/` | 加减乘除 |
| 比较 | `>` `<` `>=` `<=` `==` `=` | 大于、小于、大于等于、小于等于、等于 |
| 逻辑 | `AND` `OR` `NOT` | 与、或、非 |

### 颜色修饰

公式输出变量可以通过修饰符控制图表显示样式：

| 修饰符 | 说明 |
|--------|------|
| `COLORSTICK` | 以柱状图显示 |
| `COLORRED` | 红色显示 |
| `COLORGREEN` | 绿色显示 |
| `COLORBLUE` | 蓝色显示 |
| `COLORWHITE` | 白色显示 |
| `COLORYELLOW` | 黄色显示 |
| `LINETHICK2` | 线宽2 |
| `VOLSTICK` | 成交量柱状（颜色随涨跌变化） |

## 4. 公式编写示例

### 示例1：简单均线指标

```text
MA1:MA(CLOSE,5);
MA2:MA(CLOSE,10);
```

最简单的均线指标，输出 5 日和 10 日均线。

### 示例2：MACD 指标（含参数）

```text
SHORT:=12;
LONG:=26;
MID:=9;
DIF:EMA(CLOSE,SHORT)-EMA(CLOSE,LONG);
DEA:EMA(DIF,MID);
MACD:(DIF-DEA)*2,COLORSTICK;
```

输出 DIF、DEA 和 MACD 柱状线。

### 示例3：选股公式（均线多头排列）

```text
MA5:=MA(CLOSE,5);
MA10:=MA(CLOSE,10);
MA20:=MA(CLOSE,20);
MA60:=MA(CLOSE,60);
XG:MA5>MA10 AND MA10>MA20 AND MA20>MA60;
```

以 `XG:` 为输出变量名的选股公式，返回 1（符合条件）或 0（不符合）。

### 示例4：专家系统公式（MACD买卖信号）

```text
DIF:=EMA(CLOSE,12)-EMA(CLOSE,26);
DEA:=EMA(DIF,9);
ENTERLONG:CROSS(DIF,DEA);
EXITLONG:CROSS(DEA,DIF);
```

专家系统使用 `ENTERLONG:`（买入信号）和 `EXITLONG:`（卖出信号）定义买卖点。

### 示例5：自定义指标 - RSI

```text
N1:=6;
N2:=12;
N3:=24;
LC:=REF(CLOSE,1);
RSI1:SMA(MAX(CLOSE-LC,0),N1,1)/SMA(ABS(CLOSE-LC),N1,1)*100;
RSI2:SMA(MAX(CLOSE-LC,0),N2,1)/SMA(ABS(CLOSE-LC),N2,1)*100;
RSI3:SMA(MAX(CLOSE-LC,0),N3,1)/SMA(ABS(CLOSE-LC),N3,1)*100;
```

输出 6 日、12 日、24 日三种周期的 RSI 值。

### 示例6：自定义指标 - BOLL

```text
N:=20;
P:=2;
MID:MA(CLOSE,N);
UPPER:MID+P*STD(CLOSE,N);
LOWER:MID-P*STD(CLOSE,N);
```

输出中轨、上轨和下轨三条布林线。

## 5. API 接口文档

所有接口均以 `/api/formula` 为前缀，通过 FastAPI 路由提供。

### 5.1 引擎健康检查

**GET** `/api/formula/health`

检查 HQChartPy2 公式引擎的健康状态。

**请求示例**：

```bash
curl http://localhost:8000/api/formula/health
```

**响应示例**（引擎就绪）：

```json
{
  "status": "ready",
  "version": "1.0",
  "error": null
}
```

**响应示例**（引擎不可用）：

```json
{
  "status": "unavailable",
  "error": "HQChartPy2 引擎不可用，请检查导入"
}
```

**响应字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `status` | string | `"ready"` 表示引擎就绪，`"unavailable"` 表示不可用 |
| `version` | string | HQChartPy2 引擎版本号，如 `"1.0"` |
| `error` | string/null | 引擎不可用时返回错误信息 |

---

### 5.2 验证公式语法

**POST** `/api/formula/validate`

对公式脚本做语法检查，返回结构化验证结果。

**请求示例**：

```bash
curl -X POST http://localhost:8000/api/formula/validate \
  -H "Content-Type: application/json" \
  -d '{
    "script": "MA1:MA(CLOSE,5);",
    "formula_type": "indicator"
  }'
```

**请求参数说明**：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `script` | string | 是 | - | 公式脚本内容 |
| `formula_type` | string | 否 | `"indicator"` | 公式类型：`indicator` / `xg` / `exp`（xg 类型会检查 XG: 输出变量） |

**响应示例**（验证通过）：

```json
{
  "valid": true,
  "outvars": ["MA1"],
  "errors": []
}
```

**响应示例**（验证失败）：

```json
{
  "valid": false,
  "outvars": [],
  "errors": ["未找到输出变量（以 : 开头），请至少定义一个输出变量"]
}
```

**响应字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `valid` | bool | 公式是否通过语法检查 |
| `outvars` | array | 解析到的输出变量名列表 |
| `errors` | array | 错误信息列表（空数组表示无错误） |

**验证规则**：
1. 每条语句必须以分号（`;`）结尾
2. 必须至少有一个输出变量（以 `:` 开头而非 `:=`）
3. 输出变量名不能与保留字冲突（CLOSE/OPEN/HIGH/LOW/VOL/MA 等）
4. 选股公式（formula_type=xg）必须包含 `XG:` 输出变量

### 5.4 创建公式

**POST** `/api/formula/create`

创建用户自定义公式。

**请求示例**：

```bash
curl -X POST http://localhost:8000/api/formula/create \
  -H "Content-Type: application/json" \
  -d '{
    "name": "我的自定义均线",
    "description": "5日与20日均线交叉指标",
    "category": "indicator",
    "script": "MA5:MA(CLOSE,5);\nMA20:MA(CLOSE,20);\nCROSS:CROSS(MA5,MA20);",
    "args": [],
    "formula_type": "indicator"
  }'
```

**请求参数说明**：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `name` | string | 是 | - | 公式名称 |
| `description` | string | 否 | `""` | 公式描述 |
| `category` | string | 否 | `"indicator"` | 公式分类：`indicator` / `xg` / `exp` |
| `script` | string | 是 | - | 公式脚本内容 |
| `args` | array | 否 | `[]` | 参数列表，每项含 `name`、`value`、`description` |
| `formula_type` | string | 否 | `"indicator"` | 公式类型：`indicator` / `xg` / `exp` |

**响应示例**：

```json
{
  "success": true,
  "data": {
    "id": "a1b2c3d4e5f6"
  }
}
```

### 5.5 更新公式

**PUT** `/api/formula/{formula_id}`

更新用户自定义公式。**内置公式不可修改**，尝试修改会返回 400 错误。

**请求示例**：

```bash
curl -X PUT http://localhost:8000/api/formula/a1b2c3d4e5f6 \
  -H "Content-Type: application/json" \
  -d '{
    "name": "更新后的均线名称",
    "description": "更新后的描述",
    "script": "MA5:MA(CLOSE,5);\nMA20:MA(CLOSE,20);"
  }'
```

**请求参数说明**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 否 | 新的公式名称 |
| `description` | string | 否 | 新的公式描述 |
| `category` | string | 否 | 新的公式分类 |
| `script` | string | 否 | 新的公式脚本 |
| `args` | array | 否 | 新的参数列表 |
| `formula_type` | string | 否 | 新的公式类型 |

**响应示例**：

```json
{
  "success": true
}
```

**错误响应**：

| HTTP 状态码 | 说明 |
|-------------|------|
| 400 | 尝试修改内置公式 |
| 404 | 公式不存在 |

### 5.7 测试指标公式

**POST** `/api/formula/test`

对指定股票执行指标公式计算，返回计算结果。

**请求示例**：

```bash
curl -X POST http://localhost:8000/api/formula/test \
  -H "Content-Type: application/json" \
  -d '{
    "script": "MA1:MA(CLOSE,5);\nMA2:MA(CLOSE,10);",
    "stock_code": "000001",
    "period": "1d",
    "args": {}
  }'
```

**请求参数说明**：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `script` | string | 否 | `"MA1:MA(CLOSE,5);"` | 公式脚本 |
| `stock_code` | string | 否 | `"000001"` | 股票代码（如 "000001"、"600000"） |
| `period` | string | 否 | `"1d"` | 分析周期，可选值：`1d`（日线）、`1wk`（周线）、`1mon`（月线）、`1m`（1分钟）、`5m`（5分钟）、`15m`（15分钟）、`30m`（30分钟）、`60m`（60分钟） |
| `args` | object | 否 | `{}` | 公式参数值 |

**响应示例**（成功）：

## 6. 在股票池中使用公式

### 步骤1：创建或选择公式

在公式管理页面（或通过 API `POST /api/formula/create`）创建你需要的公式，或从内置公式库中选择合适的公式。

- 指标公式：用于技术指标计算和排序（如均线、MACD、KDJ）
- 选股公式：用于条件筛选（如均线多头排列、MACD 金叉）
- 专家系统公式：用于买卖信号判断（如 MACD 买卖点）

### 步骤2：添加转移条件节点

在股票池编辑器中，从源节点（如证券池）拖出一条流程线连接到目标节点，即可创建转移条件。

### 步骤3：选择公式类型

在转移条件编辑器中，选择"选择公式"选项卡，从以下五种公式类别中选择：

| 类别 | 对应 nset | 说明 |
|------|-----------|------|
| 技术指标 | nset=0 | 使用指标公式进行条件判断或排序 |
| 条件选股 | nset=1 | 使用选股公式进行信号判断（0/1） |
| 交易系统 | nset=2 | 使用专家系统公式判断买卖信号 |
| 基本面条件 | nset=3 | 基于财务数据标量筛选 |
| 动态行情 | nset=4 | 基于实时行情数据筛选 |

### 步骤4：选择公式或手动输入

你可以：

- **从公式库选择**：在左侧公式树中浏览并选择系统内置公式或自定义公式
- **手动输入公式脚本**：直接在公式编辑区输入通达信公式语法脚本

### 步骤5：配置公式参数

为公式配置参数值。例如，对于 MACD 指标，可以设置 SHORT=12、LONG=26、MID=9。

对于技术指标（nset=0），还需配置操作符：

| 操作符 | 说明 |
|--------|------|
| 等于 | 指标值等于目标值时通过 |
| 大于 | 指标值大于目标值时通过 |
| 小于 | 指标值小于目标值时通过 |
| 上穿（金叉） | 短线上穿长线（如 MA5 上穿 MA20） |
| 下穿（死叉） | 短线下穿长线 |
| 排名前N | 按指标值降序取前 N 名 |
| 排名后N | 按指标值升序取前 N 名 |
| 上拐 | 指标值由降转升 |
| 下拐 | 指标值由升转降 |

### 步骤6：运行股票池查看结果

配置完成后，运行股票池即可看到公式条件筛选的结果。符合条件的股票会从源节点转移到目标节点。

## 7. 常见问题

### 引擎不可用怎么办？

**现象**：调用 `/api/formula/health` 返回 `status: "unavailable"`。

**排查步骤**：

1. **检查 HQChartPy2 是否已安装**：确认 `vendor/` 目录下存在 `HQChartPy2` 模块
2. **检查 Python 环境**：HQChartPy2 是 C++ 扩展，需要匹配的 Python 版本和架构（32位/64位）
3. **查看日志**：检查 meta_core 日志中是否有 `"HQChartPy2 导入失败"` 或 `"HQChartPy2 Initialization 失败"` 的警告
4. **降级方案**：如果 HQChartPy2 不可用，系统会自动降级到通达信 TQ 量化 DLL（TPythClient.dll），前提是本地通达信客户端已安装并运行

### 公式脚本语法错误排查

**常见错误**：

1. **缺少分号**：每条语句必须以 `;` 结尾
   ```
   // 错误
   MA1:MA(CLOSE,5)
   // 正确
   MA1:MA(CLOSE,5);
   ```

2. **变量名与函数名冲突**：不要使用 `CLOSE`、`OPEN`、`MA` 等保留字作为变量名

3. **输出变量名缺失**：必须至少有一个输出变量（以 `:` 开头而非 `:=`）
   ```
   // 错误（所有变量都是中间变量）
   MA5:=MA(CLOSE,5);
   MA10:=MA(CLOSE,10);
   // 正确
   MA5:MA(CLOSE,5);
   MA10:MA(CLOSE,10);
   ```

4. **选股公式缺少 XG 输出**：选股公式必须以 `XG:` 作为输出变量
   ```
   // 正确
   MA5:=MA(CLOSE,5);
   MA10:=MA(CLOSE,10);
   XG:MA5>MA10;
   ```

5. **非 ASCII 字符**：公式脚本中不要包含中文等非 ASCII 字符，引擎会将其替换为 ASCII 占位符

### 如何调试公式计算？

1. **使用 API 测试接口**：调用 `POST /api/formula/test` 对单只股票测试公式
2. **查看日志**：设置日志级别为 DEBUG，可看到每个代码的公式计算详情
3. **分步验证**：将复杂公式拆分为简单部分，逐步验证每部分的计算结果
4. **使用内置公式作为参考**：参考 `config/builtin_formulas.json` 中的公式写法

### 数据源配置注意事项

- **K 线数据量**：公式计算需要的 K 线数据量取决于公式中使用的最大周期参数。例如，`MA(CLOSE, 60)` 需要至少 60 根 K 线数据
- **周期映射**：meta_core 内部的周期整数与 HQChart 引擎的周期 ID 自动映射，无需手动配置
- **复权处理**：引擎默认使用不复权数据（`Right=0`），如需复权数据需在配置中指定
- **数据源降级链**：系统按 `hqchart → tq_dll → tq_sdk → akshare` 的优先级自动选择数据源，可关注日志确认当前使用的数据源
