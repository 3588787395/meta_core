## 一、数据源解决方案（Data Source Architecture）

### 1.1 数据分层模型

实现严格的三层数据架构：

```
Layer 1: 历史基座层（本地静态）
  ├── 日线历史（前复权）：`data/history_1d/{symbol}.parquet`
  ├── 分钟历史（前复权）：`data/history_1m/{symbol}.parquet`
  ├── 板块成分股：`meta.db` → sectors / sector_members
  └── 财务数据：`data/fundamental/{report_date}.parquet`

Layer 2: 今日增量层（盘中动态）
  ├── 分钟合成器：`Min1Aggregator`（内存数组，5000+ 标的）
  ├── 当日Tick缓存：当前分钟未闭合数据（循环缓冲区，每标的最多100条）
  └── 今日已闭合分钟：`data/today_1m/{date}/{symbol}.pkl`（日终合并入历史层）

Layer 3: 实时流层（行情接入）
  ├── TQ DLL 实时回调：Tick 流接入
  ├── AKShare 异步轮询：备用实时数据
  └── 回放模式：KLineReplayEngine 模拟 Tick
```

### 1.2 全市场分钟合成器（Min1Aggregator）

**性能目标**：
- 单 Tick 处理延迟：P99 < 1ms
- 全市场 5000 标的聚合内存占用：< 300MB
- 分钟切换归档延迟：< 5ms

**实现要求**：

```python
# services/minute_aggregator.py
import numpy as np
from collections import defaultdict

class Min1Aggregator:
    """
    全市场分钟线合成器（无锁、预分配、批量处理）
    """

    def __init__(self, symbols: List[str]):
        self.n = len(symbols)
        self.sym2idx = {s: i for i, s in enumerate(symbols)}

        # 预分配 numpy 数组（避免 Python 对象开销）
        self.cur_min = np.zeros(self.n, dtype=np.int32)      # 当前分钟 HHMM
        self.open = np.zeros(self.n, dtype=np.float32)
        self.high = np.zeros(self.n, dtype=np.float32)
        self.low = np.zeros(self.n, dtype=np.float32)
        self.close = np.zeros(self.n, dtype=np.float32)
        self.vol = np.zeros(self.n, dtype=np.int64)

        # 已闭合分钟线：按标的分桶，避免全局锁
        self.closed_bars = defaultdict(lambda: deque(maxlen=240))  # 保留当日已闭合

    def on_tick(self, symbol: str, tick: Tick):
        """单 Tick 处理（热路径）"""
        idx = self.sym2idx.get(symbol)
        if idx is None:
            return  # 非监控标的，直接丢弃

        min_id = tick.time // 100  # HHMM

        if min_id != self.cur_min[idx]:
            self._close_bar(symbol, idx)
            self.cur_min[idx] = min_id
            self.open[idx] = tick.price
            self.high[idx] = tick.price
            self.low[idx] = tick.price
            self.vol[idx] = 0

        # 更新当前分钟（分支预测友好）
        if tick.price > self.high[idx]:
            self.high[idx] = tick.price
        elif tick.price < self.low[idx]:
            self.low[idx] = tick.price
        self.close[idx] = tick.price
        self.vol[idx] += tick.volume

    def on_tick_batch(self, ticks: List[Tick]):
        """批量处理（Python GIL 优化）"""
        # 按分钟切换与否分组，减少条件分支
        for tick in ticks:
            self.on_tick(tick.symbol, tick)

    def _close_bar(self, symbol: str, idx: int):
        """闭合上一分钟，归档到内存队列"""
        if self.cur_min[idx] == 0:
            return
        self.closed_bars[symbol].append({
            'time': self.cur_min[idx],
            'open': self.open[idx],
            'high': self.high[idx],
            'low': self.low[idx],
            'close': self.close[idx],
            'volume': self.vol[idx],
        })

    def get_today_series(self, symbol: str) -> pd.DataFrame:
        """获取某标的今日已闭合分钟线 + 当前未闭合分钟"""
        closed = list(self.closed_bars.get(symbol, []))
        idx = self.sym2idx.get(symbol)
        if idx is not None and self.cur_min[idx] > 0:
            closed.append({
                'time': self.cur_min[idx],
                'open': self.open[idx],
                'high': self.high[idx],
                'low': self.low[idx],
                'close': self.close[idx],
                'volume': self.vol[idx],
                'confirmed': False,  # 标记未闭合
            })
        return pd.DataFrame(closed)
```

## 二、公式系统优化（Formula System Optimization）

### 2.1 双引擎架构

```
公式请求
    ↓
公式路由分发器
    ├── 路径 A: HQChart 引擎（C++ 扩展，高性能，优先）
    │   ├── 适用：复杂技术指标、多周期引用、大量历史数据
    │   └── 限制：启动开销、跨进程序列化、不支持动态公式注入
    │
    └── 路径 B: Python 引擎（纯 Python fallback，轻量）
        ├── 适用：简单条件判断（C>10, MA(C,5)>MA(C,10)）
        ├── 适用：实时性要求极高的场景（盘中 Tick 级公式）
        └── 适用：HQChart 不可用时降级
```

**路由策略**：

```python
# core/formula_router.py

class FormulaRouter:
    def __init__(self):
        self.hqchart = HQChartProvider()
        self.python = PythonFormulaEngine()  # 待实现
        self.cache = FormulaCache()          # 结果缓存

    async def eval(self, formula: str, symbol: str, period: str, context: dict) -> Any:
        # 1. 检查缓存
        cache_key = self._make_key(formula, symbol, period, context)
        if cache_key in self.cache:
            return self.cache.get(cache_key)

        # 2. 按复杂度路由
        complexity = self._analyze_complexity(formula)

        if complexity == 'simple' and period in ('tick', '1m'):
            # 简单公式 + 高实时性 → Python 引擎
            result = self.python.eval(formula, symbol, period, context)
        else:
            # 复杂公式 / 多周期 → HQChart
            result = await self.hqchart.eval_async(formula, symbol, period, context)

        # 3. 写入缓存
        self.cache.set(cache_key, result, ttl=self._get_ttl(period))
        return result

    def _analyze_complexity(self, formula: str) -> str:
        """分析公式复杂度"""
        simple_funcs = {'C', 'O', 'H', 'L', 'V', 'MA', 'REF', 'CROSS', '>', '<', '>=', '<='}
        if all(t in simple_funcs for t in tokenize(formula)):
            return 'simple'
        return 'complex'
```

```python
# core/engine.py

class MetaEngine:
    async def _execute_flows(self):
        for edge in active_edges:
            if edge.strategy == 'formula_eval':
                # 获取源节点公式
                formula = edge.source.formula_decoded

                # 批量求值（向量化，避免逐只循环）
                candidates = edge.source.stocks
                results = await self.formula_router.eval_batch(
                    formula=formula,
                    symbols=candidates,
                    period=edge.period or '1d',
                )

                # 转移满足条件的股票
                passed = [s for s, ok in results.items() if ok]
                await self._transfer_stocks(edge, passed)
```

**批量求值优化**：
- 相同公式对不同股票求值时，共享编译结果
- 数据获取阶段批量加载（`SELECT ... WHERE symbol IN (...)`）
- 计算阶段使用 `numpy` 批量矩阵运算

## 五、约束与禁忌

1. **禁止**在 Tick 热路径中使用 `sqlite` 查询（必须走内存缓存）
2. **禁止**分钟合成器中使用 Python `dict` 存储单标的数据（必须用 `numpy` 数组）
3. **禁止**公式求值中逐根 K 线 Python 循环（必须用 `numpy` / `pandas` 向量化）
4. **禁止**自动 fallback 到 mock 数据源（保持现有契约行为）
5. **禁止**在盘中执行历史数据复权校准（必须开盘前完成）
6. **禁止**公式缓存跨交易日复用（日终必须清空）
