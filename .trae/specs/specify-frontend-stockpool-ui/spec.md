# 前端股票池界面功能规范 Spec

## Overview

### Summary
本规范定义 Meta Core 股票池平台前端的完整功能清单、处理流程和交互设计。前端采用单页应用架构，包含三个核心视图：主页（股票池设计与运行）、配置中心、公式管理。所有功能基于表驱动设计，通过配置表动态渲染 UI 组件。

### Purpose
提供完整的前端功能规范，作为开发、测试和评审的依据，确保前端界面简洁清晰、操作简便、功能完整。

### Target Users
- 股票池设计者：配置股票池拓扑、转移条件、运行参数
- 策略开发者：编写和管理公式
- 系统管理员：配置和管理系统参数

## Goals
- 完整实现股票池设计、运行、监控、执行的全流程 UI
- 支持设计模式、实盘模式、回放模式、仿真模式的清晰切换
- 事件面板用图标和颜色展示，可分类选择范围
- 股票池可视化包含转移条件节点，筛选条件从计算参数和 K 线配置中读取
- 前端后端解耦，前端仅通过 API 和 WebSocket 与后端交互

## Non-Goals (Out of Scope)
- 公式计算引擎后端实现（由 Python 公式插件负责）
- 数据库持久化逻辑（由后端 API 负责）
- 事件驱动引擎核心逻辑（由后端 PoolEngine 负责）

## Background & Context

前端架构基于以下核心设计原则：
- **单一真相源**：`PoolDataManager` 管理所有股票池数据和配置表缓存
- **表驱动 UI**：所有组件类型、交互行为、样式及校验规则均由后端配置表决定
- **事件驱动**：通过 WebSocket 接收后端事件，实时更新界面
- **响应式设计**：支持桌面端和移动端

## Functional Requirements

### FR-1: 股票池设计器

#### FR-1.1: 画布渲染与交互
- 画布显示股票池拓扑图（节点和边）
- 支持拖拽移动节点
- 支持缩放和适应画布
- 支持连线模式创建边
- 支持三种线形：贝兹曲线、横竖折线、直线

#### FR-1.2: 节点管理
- 添加节点：备选池、转移条件、状态池、丢弃池、文字标签
- 删除节点（含确认对话框）
- 复制/剪切/粘贴节点
- 节点层级调整（置于顶层/底层）

#### FR-1.3: 边管理
- 创建边：源节点 → 目标节点
- 删除边
- 设置边属性：触发频率、转移条件、顺序号
- 设置线条宽度和颜色

#### FR-1.4: 属性面板
- 选中节点时显示节点属性配置
- 选中边时显示边属性配置
- 配置项由后端配置表动态生成
- 支持字段联动（depends_on/active_when）
- 实时校验并显示错误信息

#### FR-1.5: 综合设置窗口
- 表格形式展示所有流程（源→条件→目标）
- 三列布局：流程标识、条件/属性、时序/操作
- 双击字段弹出字段编辑器
- 支持批量编辑和快速配置

### FR-2: 运行模式管理

#### FR-2.1: 模式切换
- 设计模式：股票池配置和编辑
- 实盘模式：实时行情数据运行
- 回放模式：历史数据回放
- 仿真模式：模拟数据运行（fz 前缀股票）

#### FR-2.2: 模式状态管理
- 模式切换时更新模式指示器
- 隐藏/显示对应模式的控制面板
- 禁止在运行中切换模式

#### FR-2.3: 运行控制
- 开始/暂停/停止按钮
- 状态栏显示运行状态
- 运行时禁用设计操作

### FR-3: 仿真模式面板

#### FR-3.1: 仿真控制面板
- 虚拟时钟显示
- 步数计数器
- 启动/暂停/步进/重置按钮
- 步长选择（1s/1min/5min/1h）
- 速度调节（0.5x - 20x）

#### FR-3.2: 仿真数据初始化
- 加载 100 只 fz 前缀股票到备选池
- 每只股票分配固定 tick 间隔（1-9秒）
- 显示初始化进度

### FR-4: 回放模式面板

#### FR-4.1: 回放控制面板
- 当前时间显示
- 进度条（当前位置/总长度）
- 播放/暂停/步进按钮
- 速度选择（1x/2x/5x/10x/100x/MAX）
- 周期选择（1min/5min/15min/30min/60min/日线）
- 日期区间选择

### FR-5: 事件面板

#### FR-5.1: 事件监控窗口
- 可拖拽浮窗
- 折叠/展开功能
- 自动滚动到最新事件
- 暂停/继续接收事件
- 清空事件列表

#### FR-5.2: 事件分类筛选
- 全选/取消全选
- 分类筛选：Tick、Bar、Formula、Edge、Transfer、Signal、Order、TTL、System
- 每种类型用不同颜色和图标标识

#### FR-5.3: 事件展示
- 时间戳
- 事件类型图标
- 事件详情（股票代码、节点ID、边ID等）
- 事件状态标识

### FR-6: K线与公式面板

#### FR-6.1: K线图表
- 股票代码选择
- 周期选择（1分钟/5分钟）
- Canvas 绘制 K线图
- 显示价格信息

#### FR-6.2: 公式结果
- 显示公式计算结果
- 实时更新

### FR-7: 配置中心

#### FR-7.1: 配置分类浏览
- 左侧分类列表
- 右侧配置表列表
- 搜索功能

#### FR-7.2: 配置表编辑
- 表格视图
- JSON 视图
- 表单视图
- 校验视图

#### FR-7.3: 热加载
- 校验全部配置
- 热加载配置变更

### FR-8: 公式管理

#### FR-8.1: 公式列表
- 搜索公式
- 按分类筛选（指标公式、选股公式、专家系统）
- 公式列表展示

#### FR-8.2: 公式编辑器
- 公式名称、分类、类型、描述
- 公式脚本编辑器
- 参数列表管理（添加/删除参数）
- 保存/测试/删除按钮

#### FR-8.3: 公式测试
- 选择股票代码和周期
- 执行测试并显示结果
- 支持选股公式批量测试

### FR-9: 股票池导入导出

#### FR-9.1: 导入功能
- DZH 格式 XML 导入
- TDX 格式 XML 导入
- JSON 格式导入
- 文件拖拽上传
- 导入预览

#### FR-9.2: 导出功能
- DZH 格式 XML 导出
- TDX 格式 XML 导出
- JSON 格式导出

#### FR-9.3: 保存功能
- 保存到服务器（API）
- 本地存储（localStorage）

### FR-10: 股票池列表

#### FR-10.1: 列表展示
- 通达信池列表
- 大智慧池列表
- 示例池列表
- 已保存池列表
- 搜索功能

#### FR-10.2: 列表操作
- 加载股票池
- 删除股票池
- 重命名股票池

### FR-11: 上下文菜单

#### FR-11.1: 画布右键菜单
- 添加节点（子菜单）
- 属性
- 综合设置
- 复制/剪切/粘贴
- 层级调整

- 缩放比例

## Non-Functional Requirements

### NFR-1: 性能
- 画布渲染响应时间 < 100ms
- 事件面板更新响应时间 < 50ms
- 支持 100+ 节点的股票池

### NFR-2: 可用性
- 操作流程直观，符合用户习惯
- 错误信息清晰明确
- 支持键盘快捷键（撤销 Ctrl+Z、重做 Ctrl+Y）

### NFR-3: 响应式
- 支持桌面端（1200px+）
- 支持平板端（768px-1199px）
- 支持移动端（<768px）

### NFR-4: 可维护性
- 代码结构清晰，模块化设计
- 注释充分，便于理解
- 遵循表驱动设计原则

## Constraints

### Technical
- 前端框架：原生 JavaScript（无第三方框架）
- 构建工具：无（直接引用 JS/CSS 文件）
- 浏览器兼容：Chrome ≥ 80, Firefox ≥ 75

### Dependencies
- 后端 API：`/api/*` 端点
- WebSocket：`/ws/events` 事件推送
- 公式插件：HQChartPy2（Python 后端）

## Assumptions
- 后端 API 已实现并正常运行
- WebSocket 连接稳定可靠
- 用户具有基本的股票池操作知识

## Acceptance Criteria

### AC-1: 股票池设计功能完整
- **Given**：用户进入主页并加载示例池
- **When**：用户创建节点、连接边、配置属性
- **Then**：所有操作正确执行，画布实时更新
- **Verification**：`human-judgment`

### AC-2: 四种模式切换正确
- **Given**：股票池已加载
- **When**：用户在设计/实盘/回放/仿真模式间切换
- **Then**：模式指示器更新，对应控制面板显示/隐藏正确
- **Verification**：`programmatic`

### AC-3: 仿真模式运行正确
- **Given**：切换到仿真模式并点击开始
- **When**：仿真运行 ≥300 秒虚拟时钟
- **Then**：事件面板显示完整事件链，股票正确流转
- **Verification**：`programmatic`

### AC-4: 事件面板分类展示
- **Given**：仿真运行中
- **When**：用户切换不同事件分类筛选
- **Then**：事件按分类正确显示/隐藏，颜色和图标正确
- **Verification**：`human-judgment`

### AC-5: 公式管理功能完整
- **Given**：用户进入公式管理页面
- **When**：用户创建、编辑、测试公式
- **Then**：所有操作正确执行，测试结果正确显示
- **Verification**：`human-judgment`

### AC-6: 配置中心功能完整
- **Given**：用户进入配置中心
- **When**：用户查看、编辑、校验配置表
- **Then**：所有操作正确执行，热加载生效
- **Verification**：`human-judgment`

### AC-7: 导入导出功能完整
- **Given**：股票池已设计完成
- **When**：用户导入/导出不同格式文件
- **Then**：导入导出成功，数据一致性保证
- **Verification**：`programmatic`

### AC-8: 响应式布局正确
- **Given**：页面在不同设备上打开
- **When**：调整浏览器窗口大小
- **Then**：布局自适应，功能正常使用
- **Verification**：`human-judgment`
