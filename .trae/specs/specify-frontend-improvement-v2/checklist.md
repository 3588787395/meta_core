# Meta Core 股票池平台 - 前端完善检查清单 V2

## 评审打分规则

- 每项检查点通过得满分，部分通过按比例扣分，未通过扣全部分。
- 任务总分 = 各检查点得分之和 / 检查点满分之和 × 100。
- **门槛：≥ 98 分方可进入下一任务；< 98 分打回架构工程师重做。**
- 评审工程师须给出：①总分 ②每项扣分理由 ③重做清单（若 < 98）。
