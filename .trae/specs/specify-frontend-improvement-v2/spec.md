# Meta Core 股票池平台 - 前端完善规范 V2

## Overview

### Summary

本规范基于 `specify-frontend-improvement` 第一版执行结果，针对未闭环项（仿真运行 ≥300 秒事件链、股票正确流转、事件面板时间分布图、转移条件节点可视化）创建**新执行规范**。目标是通过 Playwright + eventtest 混合验证，确保前端界面简洁清晰、所有股票池功能正确、符合表驱动与事件驱动原则。

### Purpose

作为前端完善第二轮执行的依据，覆盖股票池设计器、事件面板、属性面板、仿真/回放面板、公式管理、配置中心，确保每个控件和方法属性事件都能正确工作。

### Target Users

* 股票池设计者、策略开发者、系统管理员。

## Goals

* 股票池可视化完整包含转移条件节点，筛选条件从计算参数和 K 线配置读取。

* 事件面板用图标和颜色展示，支持分类矩阵、散点分布、定时器队列时间分布图。

* 四种模式（设计/实盘/回放/仿真）切换简洁清晰，状态正确。

* 仿真模式运行 ≥300 秒虚拟时间后，事件面板显示完整事件链，股票正确流转。

* 公式管理、配置中心、导入导出、响应式布局等功能完整。

* 所有验证通过 Playwright + eventtest 量化评审。

## Non-Goals (Out of Scope)

* 后端公式计算引擎、数据库持久化、事件驱动引擎核心逻辑。

* 引入第三方前端框架。

## Background & Context

### 架构设计原则

* **表驱动 UI**：组件类型、交互行为、样式、校验规则由后端配置表决定。

* **事件驱动**：通过 WebSocket/SSE 接收后端事件，实时更新界面。

* **单一真相源**：`PoolDataManager` 管理股票池数据和配置表缓存。

* **前端后端解耦**：前端仅通过 API 和 WebSocket 与后端交互。

### 核心文件结构

```
web/
├── index.html
├── css/styles.css
└── js/
    ├── canvas.js      # FlowCanvas + DZH颜色工具 + 节点/边渲染
    ├── ui.js          # TableDrivenPanel + EventPanel + FormulaManager
    └── app.js         # PoolDataManager + 模式/仿真/回放/图表
```

## Functional Requirements

### FR-1: 股票池设计器（画布引擎）

* 画布正确显示股票池拓扑图（节点和边）。

* 支持拖拽移动节点、缩放（0.1-5x）、适应画布、三种线形。

* 支持框选、迷你地图、节点选中、大小调整、高亮闪烁。

* 运行模式下禁用编辑。

* **转移条件节点**：正确渲染 `transfer_condition`（三角形）和 `condition`（紫色矩形）。

* **边条件摘要**：边标签显示触发频率 + 从 `edge.params` 读取的计算参数和 K 线配置摘要。

### FR-2: 属性面板（TableDrivenPanel）

* 选中节点/边时显示对应属性配置。

* 配置项由后端配置表动态生成，支持字段联动（depends\_on / active\_when）。

* 选中边时，面板读取 `edge.params` 中的：

  * 计算参数：`formula_ref`、`operator`、`threshold`、`nset`、`noperate`

  * K 线配置：`period`、`length`、`bar_type`

* 实时校验并显示错误信息，DZH 颜色可视化，位标志自动编解码。

### FR-3: 运行模式管理

* 设计/实盘/回放/仿真四种模式切换正确。

* 模式指示器颜色和标签更新正确（设计=蓝、实盘=绿、回放=橙、仿真=紫）。

* 运行中禁止切换模式并显示提示。

* 仿真面板：虚拟时钟、步数、启动/暂停/步进/重置、步长、速度调节。

### FR-4: 事件面板（EventPanel）

* 可拖拽浮窗，折叠/展开，暂停/继续，清空事件，状态持久化到 localStorage。

* 分类矩阵：9 类事件每类一行，显示图标/名称/计数，右侧时间轴分布事件图标。

* 散点分布：全部事件绘制在同一 Canvas，Y 轴语义与分类矩阵一致，包含统计数量，支持点击交互。

* 定时器队列：独立区域显示排队中的 timer 事件，顶部 Canvas 绘制 fire\_at 时间分布图，标识当前时间线和过期事件。

* 点击分类行/图标在下方详情区显示事件文本记录。

### FR-5: K 线与公式面板

* K 线图支持股票代码和周期选择（1 分钟/5 分钟）。

* 公式结果面板实时显示 `FormulaEvaluated` / `StockFiltered` 结果。

### FR-6: 配置中心与公式管理

* 配置分类浏览、配置表编辑（表格/JSON/表单/校验视图）、热加载。

* 公式列表、公式编辑器、参数管理、公式测试。

### FR-7: 导入导出与股票池列表

* DZH XML / TDX XML / JSON 导入导出，文件拖拽上传，导入预览。

* 股票池列表展示（通达信/大智慧/示例/已保存），加载/删除/重命名。

### FR-8: 响应式布局与状态栏

* 桌面端三栏布局，平板端自适应，移动端底部导航 + 浮动按钮 + 汉堡菜单。

* 状态栏显示就绪状态、节点数/连线数、鼠标坐标、当前时间、缩放比例。

## Non-Functional Requirements

### NFR-1: 性能

* 画布渲染 < 100ms，事件面板更新 < 50ms。

* 支持 100+ 节点，虚拟滚动支持 1000+ 股票列表。

### NFR-2: 可用性

* 操作流程直观，错误信息清晰，支持 Ctrl+Z / Ctrl+Y，拖拽流畅，操作有反馈。

### NFR-3: 可维护性

* 模块化，配置表与代码分离，消除重复代码。

## Constraints

* 原生 JavaScript（无第三方框架），ES Module IIFE 封装。

* 浏览器兼容 Chrome ≥ 80, Firefox ≥ 75。

* 仿真模式下股票代码用 `fz` 前缀。

## Acceptance Criteria

### AC-1: 股票池设计功能完整

* **Given** 用户加载示例池

* **When** 创建节点、连接边、配置属性

* **Then** 画布实时更新，转移条件节点和边条件摘要正确显示

### AC-2: 四种模式切换正确

* **Given** 股票池已加载

* **When** 切换设计/实盘/回放/仿真模式

* **Then** 模式指示器、控制面板、运行状态正确

### AC-3: 仿真模式运行正确

* **Given** 仿真模式并点击开始

* **When** 运行 ≥300 秒虚拟时间

* **Then** 事件面板显示完整事件链，股票正确流转（备选池→A/B→C池）

### AC-4: 事件面板可视化

* **Given** 仿真运行中

* **When** 事件到达

* **Then** 分类矩阵/散点分布/定时器队列正确显示，点击可查看详情

### AC-5: 公式与配置管理完整

* **Given** 用户进入公式管理/配置中心

* **When** 创建、编辑、测试、保存、热加载

* **Then** 操作正确执行，界面实时更新

### AC-6: 导入导出与列表

* **Given** 股票池已设计完成

* **When** 导入/导出 DZH/TDX/JSON，操作股票池列表

* **Then** 数据一致性保证

### AC-7: 响应式布局

* **Given** 不同设备尺寸

* **When** 调整窗口

* **Then** 布局自适应，功能可用

### AC-8: Playwright 验证

* **Given** 前端服务正常运行

* **When** 执行 Playwright 脚本

* **Then** 模式切换、仿真运行、事件接收、导入导出、转移条件节点全部通过
